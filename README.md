# Free CV Maker

Free browser-based CV and resume editor for [free-cv-maker.web-free.site](https://free-cv-maker.web-free.site).

## Upstream

Built on [OpResume](https://github.com/oopooa/opresume) by **oopooa**, **MIT License** (`LICENSE`). See `/about` for attribution.

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

Deploy is configured via `wrangler.toml` (not run from this agent).
